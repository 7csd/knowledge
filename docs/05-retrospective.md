# 项目复盘

## 最难的问题

我认为最难的是让答案得到完整证据支持，而不只是检索到相似文字。跨页表格的金额、续行和共同注释必须一起读取，多版本制度还需要核对适用范围和替代关系。n08首次拼接引文被拒、c02首轮漏检指定条款，暴露了这两类问题。

## 我的改进与收获

我在方案中分离检索片段和可引用原文，增加父条款、续行及注释的关联读取，并保留校验失败后的修正过程。版本更新采用MD5去重和增量保留，D11新增17点版后，回答从18点结论变为双版本冲突追问。

通过这些测试，我明确了三个区别：检索命中不等于可以回答，摘录存在不等于支持结论，日期较新不等于自动生效。混合首轮指定证据召回率为94.12%，即使后续读取补齐，也不能把首轮成绩写成100%。

我还认识到，Agent的关键在于观察工具结果后改变动作。正常问题可以读原文后结束；遇到冲突要补查，遇到失败要判断重试或停止，达到预算则明确返回未完成。

## 下一步

后续我会扩充独立测试集，复核答案与引文的语义支持性，重点改进冲突资料召回和引用覆盖，并比较不同模型、召回参数下的效果及成本。
