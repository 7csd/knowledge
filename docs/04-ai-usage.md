# AI 使用说明

## 使用范围

我使用Codex辅助完成需求整理、方案比较、代码与合成资料生成、测试执行、问题修正和文档编写。AI参与了LangGraph工具循环、混合检索、原文校验、多格式解析、增量入库及评估脚本的实现。

## 我的方案选择与调整

我确定了Python + LangGraph、BM25与中文向量混合召回、原文核验的路线，并将工作重点放在核心问答链路及测试证据上。我要求先完成工程再配置对话模型，暂不加入Rerank；资料处理采用MD5去重、新旧版本同时保留，不按日期覆盖。根据测试反馈，项目修正了D11版本保留、默认数据测试夹具和表格引文处理。

## 验证方式与边界

我采用工程测试、真实BGE检索测试和Codex代行决策测试分层验证。代行测试通过文件桥接逐轮观察真实工具结果，保存30题及1题版本对照的输入、输出、Trace和评分。n04标注更正、n08首次引文失败及后续修正均保留记录。

offline_scripted是预设回放，assistant_in_the_loop是Codex代行决策；对话接口支持由运行者通过本地环境变量选择兼容模型。当前用例设计、作答和评分均有同一AI参与，评分存在自评偏差。真实密钥保存在本地环境配置中，不进入仓库。
