# 需求说明

## 用户与目标

我将项目定位为面向企业员工的制度与产品FAQ问答助手。输入问题及可选对话历史，基于带文档ID、版本日期的合成资料，给出可靠、有出处的回答。

## 范围与成功标准

我采用单Agent和CLI入口，实现文档检索与原文读取、模型工具循环、引用校验、预算、失败处理和Trace，不包含UI、部署及多Agent。

- 输出answer、citations、gaps、conflicts、status，包含原文、文档ID及版本。
- 模型根据工具观察选择补查、读取、追问或结束，提供至少两条不同的实际决策路径。
- 冲突先查证，缺少适用范围或替代依据时列出双方并追问，不按日期选新版。
- 覆盖明确答案、文档冲突、资料外、相似改写、上下文追问、工具失败。
- 达到执行上限明确未完成；文档变化后核对答案及动作变化。
- 保留至少三组实际输入、输出及Trace，区分离线工程与真实模型测试。
- 提供复现命令、测试记录、AI使用和复盘，交付GitHub URL及最终commit SHA，不提交真实密钥。

完成情况见 [测试记录](03-evaluation.md)。
